# Rohan AI Agent

A personal AI-agent starter for answering questions about Rohan's bio, skills, projects, coding profiles, experience and other profile information.

## Stack
- React + Vite
- Tailwind CSS
- Node.js + Express
- OpenAI-compatible chat API endpoint
- JSON knowledge base

## Run

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

Create `backend/.env` from `.env.example`.

The frontend expects the backend at `http://localhost:5000`.
